# AI Prompts Directory

This directory contains AI prompt templates for the trading system.

## Files

- `system_prompt.txt` - Default system prompt for AI trading decisions
- `strategy_examples/` - Example strategy prompts (to be added in Phase 3)

## Usage

These prompts are loaded by the AI decision engine and can be customized per trader or globally.

Phase 3 will implement the full prompt templating system.
